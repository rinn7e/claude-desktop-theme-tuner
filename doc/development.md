# Development

A pnpm workspace: the web app is in `package/web-app`, the mod in
`package/claude-mod`. Follow the [code convention](code-convention.md).

## Run

Node.js 24+ and pnpm, from the repository root:

```bash
pnpm install
pnpm run dev
```

`pnpm run build` writes a static site to `package/web-app/dist/`. Every push
to `master` deploys it to GitHub Pages (`.github/workflows/pages.yml`).

## Check

From the root: `pnpm run check`, `pnpm run lint`, `pnpm run format:check`,
`pnpm run test`.

The mod has its own checks, run by Claude Code:
`claude plugin validate package/claude-mod` and
`claude plugin test package/claude-mod`. How to get its types for the editor
is in [its README](../package/claude-mod/README.md).

## Keep in step

- The presets of the mod (`package/claude-mod/hooks/presets.ts`) are
  generated from the presets of the web app: after changing a preset,
  `pnpm test -u` writes them again.
- `package/claude-mod/hooks/make-colors.js` is the own file of Claude, copied
  unchanged from the mod-authoring skill: copy it again when Claude updates.
- `package/web-app/src/theme/code-syntax.ts` is generated by
  `pnpm --filter web-app code-syntax`.

## How a look is made

A mod look is not written token by token: `makeColors`
(`package/claude-mod/hooks/make-colors.js`) takes a few anchors and role
seeds, and Claude derives about 100 design system tokens from them. The mod
(`package/claude-mod/hooks/look.ts`) turns a preset into those anchors and
seeds, and checks with `makeColors` that Claude paints the result. Every
knob, the rules Claude checks and what was measured in the real app are in
[mod-knobs.md](mod-knobs.md); how the app was probed is in
[claude-internals.md](claude-internals.md).

| File                                           | Role                                                                                   |
| ---------------------------------------------- | -------------------------------------------------------------------------------------- |
| `package/claude-mod/hooks/look.ts`             | a setup to the look the mod sends, shared with the web app                             |
| `package/claude-mod/hooks/register.tsx`        | the `/theme-tuner` command, the `set_theme` tool, the pane and the start of a session  |
| `package/web-app/src/screen/home-screen/`      | the home page: the knob editor, the code panel and preview v2                          |
| `package/web-app/src/theme/claude-graph.js`    | the graph and resolver of Claude, cut from `make-colors.js` by a snapshot test         |
| `package/web-app/src/theme/code-syntax.ts`     | the syntax colors of each code theme, generated by `pnpm --filter web-app code-syntax` |
| `package/web-app/snippets/mod-look.snippet.js` | for maintainers: reports which variables paint each part of the real app under a look  |
